# Bark 消息推送（BarkNotify）

使用 [Bark](https://bark.day.app)（iOS 推送 App）转发 MoviePilot 的各类通知：资源下载、整理入库、订阅、站点、媒体服务器等。

当前版本：**v1.3.6**（更新记录见插件仓库根 `package.v3.json` 的 `history`）

## 功能

- **多用户**：通过「用户数量」下拉（1-10）控制用户槽位数，每个用户独立配置 Bark Key、通知类型、生效时间段与强提醒
- **类型过滤**：按宿主消息类型（资源下载/整理入库/订阅/站点/媒体服务器/手动处理/插件/智能体/其它）逐用户筛选，留空接收全部
- **生效时间段**：30 分钟粒度下拉选择起止时间，支持跨天（如 22:00-07:00）；时段外的消息以静默（passive）方式推送——不亮屏不响铃，只进入通知中心列表
- **强提醒**：开启后该用户的所有消息使用 critical 级别（静音也响铃，需在 Bark App 内授权「重要警告」）；时段外仍按静默处理
- **测试消息**：插件启用时自动向所有用户发送一条测试推送验证连通性（全局可关闭）
- **参数映射**：消息图片 → Bark 图标；消息链接 → 点击跳转地址；消息类型 → Bark 分组（iOS 通知中心自动归拢）
- 支持自建 Bark 服务器；可选统一铃声

## 安装

MoviePilot「设置 → 插件市场」加入本仓库地址后，在插件市场搜索「Bark」安装。

仅支持 MoviePilot V3（`system_version >= 3.0.0`）。

## 配置

### 全局设置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 发送测试消息 | 启用插件时向所有用户各发一条测试推送，验证配置连通性（可关闭） |
| Bark 服务器地址 | 默认官方 `https://api.day.app`，自建服务器在此修改 |
| 铃声 | 可选，统一指定推送铃声（如 `minuet`），留空用 App 默认 |
| 用户数量 | 控制下方用户槽位的展示数量（1-10）；调小后超出槽位的配置保留不丢失，调回即恢复 |

### 用户槽位

打开「用户N」开关后按表单填写：

| 配置项 | 说明 |
| --- | --- |
| 名称 | 自定义，用于展示与推送记录 |
| Bark Key | 在 Bark App 内复制，明文填写 |
| 通知类型 | 下拉多选，留空接收全部类型 |
| 生效开始 / 生效结束 | 30 分钟粒度下拉选择，选「全天」表示不限时段，支持跨天 |
| 强提醒 | 该用户的所有消息使用 critical 级别；时段外仍按静默处理 |

### 推送级别规则

| 场景 | Bark level | 效果 |
| --- | --- | --- |
| 生效时段外（无论是否强提醒） | `passive` | 静默：不亮屏不响铃，只进通知中心列表 |
| 生效时段内 | `active` | 正常亮屏提醒 |
| 生效时段内 + 强提醒 | `critical` | 静音也响铃（需在 Bark App 内授权「重要警告」） |

## 详情页

- **用户列表**：每个用户的通知类型、生效时段与强提醒状态
- **最近推送**：最近 20 条推送记录（时间、用户、标题、成功/失败标记）

## 注意

- 只转发宿主的广播通知（未指定专用渠道的消息），不与微信/TG 等已配置渠道重复
- 发送成功以 HTTP 200 且响应 JSON `code == 200` 判定
- Bark Key 以明文存储于 MoviePilot 配置中，请注意实例访问安全
